# Aquarela Fotografia — Landing Page Ensaio Gestante

Landing page de alta conversão para a **Aquarela Fotografia**, desenvolvida em HTML5, CSS3 e JavaScript puro. Otimizada para campanhas de Meta Ads (Instagram/Facebook Ads) com foco em agendamentos diretos no WhatsApp.

---

## 🚀 Como Instalar no cPanel

### Opção A: Instalação Via Git Version Control no cPanel (Recomendado)
1. Acesse o **cPanel** do seu domínio.
2. Procure por **Git™ Version Control** (Controle de Versão Git).
3. Clique em **Create** (Criar).
4. Insira a URL do repositório: `https://github.com/santhiagosouza/aquarela-gestantes.git`.
5. Em **Repository Path**, escolha a pasta de destino (ex: `public_html` ou `public_html/gestantes`).
6. Clique em **Create** e depois em **Deploy HEAD Commit**.

### Opção B: Instalação Manual Via Gerenciador de Arquivos (File Manager)
1. Faça o download do repositório em arquivo `.zip`.
2. Acesse o **Gerenciador de Arquivos** no cPanel.
3. Abra a pasta `public_html` (ou o subdomínio desejado).
4. Faça o upload do `.zip` e extraia os arquivos.
5. Certifique-se de que o arquivo `.htaccess` foi enviado para ativar o redirecionamento HTTPS e o cache do navegador.
